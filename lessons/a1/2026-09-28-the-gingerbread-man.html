💡 句型练习 Sentence Patterns

1. [Someone] can [verb].

“……会 / 能……”。想说自己或别人会做什么，就用 can + 动词。记住：can 后面的动词永远用原形，不加 -s。
I can run. 🏃 / He can jump. 🐸 / We can bake. 🍪 / The fox can swim. 🦊
练习：我会跑 → I can .

2. [Someone] runs past a [thing].

“……跑过……”。run past 就是“从旁边跑过去”，后面接跑过的东西（一只猫、一棵树、一栋房子）。
He runs past a cat. 🐱 / He runs past a dog. 🐶 / I run past a big tree. 🌳 / We run past the school. 🏫
练习：他跑过一只猫 → He runs past .

3. [Verb]! 一句话的口令

想让别人立刻做一件事，就把动词放在最前面，句子可以很短：Run!（跑！）Stop!（停！）。想客气一点，就在前面或后面加 please。
Run! 🏃 / Jump on my back. 🦊 / Come here, please. 👋 / Stop, please! ✋
练习：跳到我背上 → .

📐 语法点 Grammar

1. 一个东西前面加 a 或 an

说“一个”时，单词前面要加 a 或 an。
单词以元音字母 a / e / i / o / u 开头，用 an：an oven、an apple 🍎、an egg 🥚。
其他情况用 a：a fox 🦊、a river 🌊、a cat 🐱。
an oven 🔥 ←→ a fox 🦊 / an apple 🍎 ←→ a dog 🐶

2. 他 / 她 / 它 后面，动词要加 -s

当做事的是 he（他）、she（她）、it（它），或者只有一个人 / 一只动物时，动词后面要加 -s：
run → runs、say → says、smile → smiles、bake → bakes。
但 I / you / we / they 后面不加：I run、they run。
He runs fast. 🏃 / She bakes a cake. 🍪 / The fox smiles. 🦊 ←→ I run. 🏃 / They run. 🏃🏃

3. can 和 cannot：能 / 不能

can 是“能、会”，cannot（常写成 can't）是“不能、不会”。
两个词后面都跟动词原形，千万不要加 -s：要说 He can run. 不能说 He can runs。
回答别人的问题时，可以说 Yes, I can. 或 No, I cannot.
I can run. 🏃 / He cannot swim. 🌊 / The fox can help. 🦊 ←→ I can runs. ❌

🌏 中文知识扩展

🍪 姜饼人是从哪里来的？

《姜饼人》（The Gingerbread Man，也叫 The Gingerbread Boy）是一个美国的童话故事。它最早印在 1875 年 5 月的儿童杂志《圣尼古拉斯杂志》（St. Nicholas Magazine）上 📖。讲故事的人说，这个故事是一个缅因州的女孩讲给孩子们听的，孩子们太喜欢了，她就把故事记了下来。

这个故事属于“逃跑的食物”家族：很多国家都有从锅里跳出来跑掉的食物的故事。比如俄罗斯的《小圆面包》（Kolobok，中文常译作“科洛博克”，1864 年记录）、挪威的《煎饼》（Pannekaken，1842—1844 年出版）、德国的《又胖又大的煎饼》、法国的《滚动的薄饼》。它们都比美国的姜饼人更早，可以说是姜饼人的“老亲戚” 🌍。

要说明一下：1875 年的原版结局里，狐狸把姜饼人吃掉了（他会喊 “I'm quarter gone... I'm all gone!”）。今天我们学的这一课用的是给小朋友改写的温和版本——狐狸帮助姜饼人过河，他平安回到了家 🏠。读故事的时候，可以和爸爸妈妈聊聊：你更喜欢哪一个结局呢？

🫚 姜饼里为什么要放姜？

  • 姜饼（gingerbread）是用面粉、蜂蜜或糖蜜、姜粉做成的点心。姜有一种暖暖的、微微辣的味道，加在甜甜的饼干里特别香 ✨。
  • 欧洲人很早就会做姜饼了。传说中世纪时人们把姜饼做成小人、小动物的形状，赶集的时候卖给小朋友。后来就有了“姜饼人” 🍪。
  • 在中国，姜也是一种很老的食材。《论语》里就记着孔子 “不撤姜食”，意思是他吃饭时总少不了姜 📜。中医也说姜能驱寒暖身，冬天喝一碗姜汤，身子马上暖起来 ♨️。
  • 因为姜饼又甜又耐放，欧洲人还喜欢用它盖房子——就是童话里的姜饼屋，屋顶上刷一层白糖霜，像下过雪一样 🏠❄️。

🎨 中国也有“可以吃的小人”：面塑与糖人

看到姜饼人，中国的小朋友一定会想到另一种老手艺——捏面人。面塑（也叫面人）是用糯米面、面粉加上颜色，用手和一小根竹刀，几下就捏出小人、小动物、故事里的人物，比如孙悟空、猪八戒 🐒。

  • 面塑在中国已经有一千多年的历史，2008 年被列入国家级非物质文化遗产名录 🏅。山东菏泽面人、北京“面人汤”、上海面塑都很有名。
  • 和面塑很像的还有 吹糖人：把麦芽糖加热变软，一边吹一边捏，转眼就变出一只亮晶晶的小老鼠或小龙 🐉。以前庙会、集市上最常见，师傅的手快得像变魔术。
  • 姜饼人是烤出来的，面人是捏出来的，糖人是吹出来的——做法不一样，但都是把好吃的面团变成一个会讲故事的小人 🍪🎨。

🦊 故事里的小道理

姜饼人跑得很快，可是一条大河就把他难住了。这告诉我们：每个人都有做不到的事，做不到的时候请别人帮忙一点也不丢脸，记得说一声 “Thank you!” 🙏。反过来说，别人帮了你，你也要像老奶奶一样笑着谢谢他 😊。

老版本里姜饼人因为太骄傲、太相信陌生人才吃了亏。所以现实生活里，遇到不认识的人搭话，小朋友要先找爸爸妈妈，不跟陌生人走，不吃陌生人给的东西 🚫。

🎮 可以这样玩

  • 念咒语比赛 🏃：全家一起念 “Run, run, run as fast as you can! You can't catch me, I'm the Gingerbread Man!”，看谁念得又快又清楚。
  • 捏一个姜饼人 🍪：用橡皮泥、面团（或者和爸爸妈妈一起烤真的饼干）做一个小人，给他点上眼睛和纽扣，边做边说 bake、oven、run。
  • 我说你做 🗣️：大人说 “Run!” “Jump on my back.” “Stop, please!”，小朋友立刻做动作，练习英文口令。
  • 画一条河 🌊：画姜饼人跑过的路线——烤箱、猫、狗、大河、狐狸、家，边画边讲一遍故事。
  • 找一找 🔍：在故事里找出所有带 -s 的动词：runs、says、smiles，说说它们为什么加 s。

⚠️ 安全提醒：烤箱非常烫，小朋友不能自己开关烤箱、不能伸手进去拿烤盘，一定要请大人帮忙，并且戴上隔热手套 🧤；烤好的饼干要放凉了再吃，刚出炉会烫到嘴巴 🔥；吃饼干前要把手洗干净 🧼；如果家里有对小麦、鸡蛋、坚果过敏的人，吃之前一定要先问清楚 ⚠️。
